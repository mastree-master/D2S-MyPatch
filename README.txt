D2 Survivors 편의 패치 (D2S-MyPatch)
=====================================

게임 파일(resources\app.asar)을 고쳐서 파밍을 편하게 해 주는 개인용 패치입니다.
원본은 자동으로 백업되고, bat 하나로 원본/패치를 오갈 수 있습니다.

※ 패치 상태에서는 순위표(래더)에 기록이 전송되지 않습니다. (아래 "순위표" 참고)
※ 비공식 패치입니다. 쓰기 전에 세이브 백업을 권장합니다.
   세이브 위치: %APPDATA%\D2 Survivors\save


1. 들어 있는 파일
-----------------
  D2S-MyPatch.bat    패치 적용 / 원래대로 복구 (실행하면 현재 상태를 보고 물어봄)
  README.txt         이 설명서


2. 설치 / 사용
--------------
  1) 게임을 완전히 끕니다.
  2) D2S-MyPatch.bat 실행 → 언어 1(한국어)
  3) "현재: 원본 상태입니다. 패치를 적용할까요?" → y
  4) "[OK] 패치 완료" 가 나오면 게임 실행

  원래대로: 다시 D2S-MyPatch.bat 실행 → "현재: 패치 상태입니다. 원본으로 복구할까요?" → y

  게임이 업데이트되면 패치가 풀립니다. 게임을 끄고 다시 패치 적용하세요.
  "이 게임 버전은 지원하지 않습니다" 가 나오면 게임 코드가 바뀐 것이라 패치 수정이 필요합니다.
  (게임 기본 설치 위치가 아니면 게임 폴더를 물어봅니다)


3. 기능
-------
[자동 습득 / 등록 / 판매]
  - 떨어진 아이템·골드·상자를 거리와 상관없이 즉시 처리 (상자 자동 열기)
  - 보관함(고유)에 없는 유니크/세트/룬워드 → 자동 등록
  - 등록된 것보다 더 좋은 것 → 자동 교체
      유니크/세트: 밀려난 이전 것은 판매
      룬워드: 같은 종류(무기 종류+한손/양손, 방어구 부위)끼리만 교체, 밀려난 것도 판매
  - 룬워드 중복
      등록된 것과 같은 종류 → 판매 (한손 무기는 1개 더 보관, 쌍수용)
      등록된 것과 다른 종류 → 종류별 가장 좋은 1개만 보관 (한손 무기 2개)
  - 퀘스트 아이템·부적 → 인벤토리 (호라드림의 고서는 판매)
  - 그 외 전부 자동 판매
  - 인벤토리가 꽉 차면 개인 창고 → 공용 창고 1~3 순서로 보관

[좋고 나쁨 판정 순서]
  1. 스킬 (+모든 기술, 기술 탭, 개별 기술 등)
  2. 오라 레벨 · 발동 기술 레벨 (적중 시/피격 시/충전 등)
  3. 그 외 옵션 수치 합 (피해, 공속, 저항 …)
  4. 방어력 (방어력 증가 %, 방어력 +)
  ※ 툴팁에 안 보이는 숨은 값(냉기 지속 시간, 최대 내구도 등)은 계산에서 제외
    대신 툴팁 맨 아래에 "숨겨진 값: …" 으로 표시

[화면 표시]
  - 왼쪽 획득 목록: [등록] [교체] [인벤] [창고] [판매] + 등급·부위
      예) [교체] 소집 (룬워드 · 무기 · 한손 · 도끼 · 에틴 액스) [되돌리기]
  - [교체] 줄에 마우스 → 이전/새 옵션 비교 창
  - [되돌리기] → 유니크/세트 교체 취소 (판 골드도 되돌림)
  - 아이템에 마우스 → 툴팁 옆에 같은 아이템이 어디 있는지 비교 상자
      등록 / 개인 창고 / 공용 창고 1~3 / 인벤
      초록 ▲ 보관본이 더 좋음 · 빨강 ▼ 보관본이 더 나쁨 · 회색 = 같음
      (착용 중인 아이템에도 표시, Shift = 착용 장비 비교)

[자동 반복]
  - 공포 영역 보스 처치 후 포털 열리면 4초 뒤 자동 입장
  - 클리어 화면에서 4초 뒤 같은 단계 재시작 ("다시 하기" 로 시작한 단계일 때)
  - 상점(T)에 들어가거나 Esc 로 끝내면 취소
  - 화면 위에 카운트다운 표시

[창 / 단축키]
  - B          : 창고 열기 (런 도중, 마을 모두)
  - Ctrl+클릭  : 인벤토리 아이템을 창고 빈자리로 (창고 창 안 열어도 됨)
  - F8         : AFK 모드 켜기/끄기
  - 캐릭터/인벤/스킬/퀘스트 창을 열어도 게임이 멈추지 않음 (Esc 만 일시정지)

[AFK 모드 (F8)]
  - 화면을 검게 덮고 진행 상황만 표시
      경과 시간, 완료한 판 수, 이전 판/평균 소요 시간,
      단계·처치·이번 판 골드, 웨이브 진행, 보유 골드,
      등록/교체/보관/판매 개수 (유니크·세트·룬워드별)
  - 창을 최소화하거나 다른 창에 가려져도 멈추지 않음
  - 클릭이 게임에 전달되지 않음 (종료 버튼 또는 F8 로 해제)
  - 주의: 켜 둔 동안에도 전투가 진행됩니다. 위험한 단계에서는 쓰지 마세요.


[자동 업데이트]
  - bat 실행 시 새 버전이 있으면 "업데이트할까요? (y/n)" → y 면 자동으로 받고 이어서 실행
  - 게임 중 새 버전이 나오면 오른쪽 아래에 "패치 업데이트 있음" 표시 (클릭하면 닫힘)
  - 배포: https://github.com/mastree-master/D2S-MyPatch


4. 순위표 (래더)
----------------
  - 패치 상태에서는 순위표로 아무 기록도 보내지 않습니다.
    게임 실행 파일에서 전송 요청을 가로채 "보낸 것" 으로 처리하므로
    "내 기록 보내기" 를 켜도 서버로 나가지 않고, 대기열에도 남지 않습니다.
  - 순위표 보기는 정상입니다.
  - 순위표에 올리려면 게임을 끄고 D2S-MyPatch.bat 로 원본으로 복구한 뒤 플레이하세요.
  - 주의: 패치 상태에서 "내 기록 보내기" 를 켜면, 패치 전에 쌓여 있던
    전송 대기 기록도 같이 지워집니다. 남겨야 할 기록이 있으면 꺼 두세요.


5. 문제가 생기면
----------------
  - 게임이 켜지지 않거나 이상하면: D2S-MyPatch.bat 실행 → y (원본으로 복구)
  - 백업 파일: 게임폴더\resources\app.asar.orig
  - 게임 업데이트 후에는 백업이 새 버전으로 다시 만들어집니다.
